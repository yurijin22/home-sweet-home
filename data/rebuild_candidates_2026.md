# 재건축 후보 분석 (2026-11)

## 판단 프레임

### 1. 용적률만 보면 안 된다 — **세대당 대지지분**이 본질

> 상계주공5단지: 용적률 **93%**(서울 최저급)인데 좁은 세대가 많아 세대당 대지지분이 적음 → **분담금 약 5억**
> 상계주공14단지: 용적률 146%인데 대지지분 13.7평 → **분담금 1.98억**

- 재건축 후 용적률이 **260% 수준**이면 기존 용적률 낮은 단지가 유리
- **300%**면 주변 시세 높은 단지가 유리
- 사업성보정계수는 **지가가 낮을수록 높게** 적용 (외곽 유리)
- 단, **분양가 낮은 외곽 과밀단지는 공사비 충당이 어려움**

### 2. 평형 배정은 **권리가액 순** — 랜덤 아님

**도시정비법 제76조**는 "종전의 면적·이용상황·환경 등을 종합 고려해 균형 있게 배분"만 정하고, **구체적 배정 방식은 조합 정관·총회 결의**로 정함.

실무 표준:

| 단계 | |
|---|---|
| 1 | 조합원이 1~3순위 희망평형 기재 |
| 2 | 평형별 1순위 희망자 먼저 배정 |
| 3 | 경쟁률 1:1 초과 시 → **종전자산 감정평가액(권리가액) 큰 순** |
| 4 | 탈락자는 2·3순위 중 남은 평형 **무작위 추첨** |
| 5 | 권리가액 동일 시 **공개추첨** |

**판례:** 서울 영등포 사례 — 조합이 권리가액 대신 "분양신청 희망순위"를 우선해 배정 → **법원이 위법으로 보고 평형 배정 취소** (분양신청 안내에 기준을 고지하지 않음). 즉 **권리가액 순이 법원이 인정하는 기준**.

### 3. 조합설립인가 후 양도 금지 (2025.10.15 대책)

서울 전역 투기과열지구 → **조합설립인가 후 조합원 지위 양도 금지**, 위반 시 **현금청산**.
→ **조합설립 전 단지만 매수 가능**하고, 사면 10년 이상 묶임. "오르면 판다"가 불가능.

### 4. 구조적 한계 (우리 예산)

> **큰 평형 = 권리가액 상위 = 84㎡ 배정 가능 = 예산 초과**
> **작은 평형 = 예산 내 = 권리가액 하위 = 배정 탈락**

**우리 예산으로 재건축에서 "면적을 늘리는" 시나리오가 성립하지 않음.** 재건축으로 넓혀 가는 건 이미 큰 집을 가진 사람의 게임.
